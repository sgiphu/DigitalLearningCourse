GitHub Pages 發布

單元 5 · 預計 90 分鐘

完成本單元後，你可以：

  • 把整個課程資料夾變成一個公開網址
  • 更新內容並讓線上版本同步更新
  • 用一份檢查清單確認網站在手機上也能正常使用

上線前先整理資料夾

GitHub Pages 會照你資料夾的結構原封不動放到網路上，所以檔名要乾淨：全部小寫、不要有空格、不要用中文檔名。首頁一定要叫 index.html，這是網址根目錄預設開啟的檔案。

mycourse/
├── index.html      ← 首頁
├── style.css       ← 共用外觀
├── unit1.html … unit5.html
└── images/         ← 圖片放這裡

發布步驟

  1. 註冊 GitHub 帳號並登入。
  2. 點右上角的 + → New repository，名稱填 mycourse，選 Public，建立。
  3. 在新的 repository 頁面點 uploading an existing file，把資料夾裡的所有檔案拖進去，然後按 Commit changes。
  4. 進入 Settings → 左側 Pages，Source 選 Deploy from a branch，分支選 main、資料夾選 / (root)，按 Save。
  5. 等一到兩分鐘重新整理，頁面上方會出現你的網址，格式是 https://你的帳號.github.io/mycourse/。

最常見的兩個問題：畫面沒有樣式，通常是 style.css 沒有一起上傳，或檔名大小寫不符；圖片破圖，通常是路徑寫成 Images/ 但實際資料夾是 images/。在自己電腦上打開看起來正常，是因為 Windows 不分大小寫，但伺服器會分。

更新內容

改完檔案後，回到 repository 把新檔案上傳覆蓋，等一兩分鐘網站就會更新。如果看到的還是舊的，先用無痕視窗開一次，多半是瀏覽器快取。

上線後的檢查清單

  • 用手機開一次，確認文字不會太小、版面沒有橫向捲動
  • 點過每一個導覽連結與上下單元連結，確認沒有 404
  • 確認影片能播放、測驗能作答
  • 圖片都有 alt 文字，影片都有字幕
  • 把網址傳給一位目標學習者，看他在哪裡卡住

本單元練習

把你的課程網站發布上線，取得公開網址，跑完上面的檢查清單，並依照試用者的回饋修改至少三個地方。

怎麼請 AI 幫忙：遇到錯誤畫面時，把整個錯誤訊息或截圖、加上你的檔案內容一起貼給 AI，說明「我完全不會寫程式，請告訴我要改哪一行、改成什麼」。描述得越具體，得到的答案越能直接用。
