# DigitalLearningCourse
Digital Learning Course
數位教材製作 — 課程網站起始檔案
================================

怎麼開始
1. 把整個 mycourse 資料夾解壓縮到桌面。
2. 用滑鼠雙擊 index.html，會用瀏覽器打開，這就是你的網站。
3. 用 VS Code 開啟這個資料夾，改檔案裡的文字，存檔後回到瀏覽器按 F5 重新整理。

檔案說明
  index.html   首頁（單元列表）
  unit1.html   單元 1：課程規劃
  unit2.html   單元 2：教材與簡報製作
  unit3.html   單元 3：教學影片製作
  unit4.html   單元 4：互動式練習（含可運作的測驗）
  unit5.html   單元 5：GitHub Pages 發布
  style.css    全站共用的外觀設定，改顏色就改檔案最上方的 :root
  images/      圖片放這裡
  videos/      影片素材放這裡（正式影片建議放 YouTube，不要放進網站）

三個安全習慣
1. 每次大改之前，先複製整個資料夾備份，命名 v1、v2、v3。
2. 只改文字，不要刪掉 < > 這類符號；改壞了就退回備份。
3. 檔名全部小寫、不要有空格與中文，上線後才不會出問題。

請 AI 幫忙時，訊息裡要包含三件事
1. 你的程度：「我完全不會寫程式」
2. 你要的東西：「請給我完整的檔案內容，不要只給片段」
3. 你現在的檔案：把整個 html 或 css 貼上去
